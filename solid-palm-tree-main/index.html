    Here's how to add your game to Nebular Launcher.

    1. Unzip the file you just downloaded. You'll get a folder (e.g. FlappyBird).
    2. Move that folder into your Nebular Launcher's Games folder, so it sits next to the other games.
    3. Open Nebular Launcher. In the header, type the folder's exact name into the “Folder name” box and press Add Game.
    4. The game appears as a tile with its icon. Click it to play.

    Tip: the folder name must match the unzipped folder exactly (capitalisation included).

    How to import into Eaglercraft

    1. Download the skin using the button above — you'll get a .png file.
    2. Open Eaglercraft and click Options… on the main menu.
    3. Go to Skin Customization….
    4. Click an empty skin slot, then Import Skin, and pick the .png you downloaded.
    5. When asked for a model, choose Classic (wide) — that's what this skin uses.
    6. Select the slot and press Done. Your skin is now equipped!
